# A2A — szkic

A2A używa tych samych kontraktów co REST i MCP. Agent może przekazać `TaskRequest`, odczytać `TaskReceipt` i otrzymać zredagowane aktualizacje statusu. Wersja 0.1 nie deklaruje jeszcze kompatybilności z konkretną wersją zewnętrznego standardu A2A; Agent Card i model uwierzytelniania wymagają decyzji właściciela produktu.

Nie jest dozwolone przekazywanie poświadczeń, grantów materialnych ani surowych logów między agentami.
