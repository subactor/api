# Worktrees — poza runtime'em v0.1

W pierwszym etapie API może co najwyżej przyjąć deklaratywną potrzebę izolowanego workspace. Nie tworzy worktree i nie wskazuje ścieżki lokalnej. Ewentualne wykonanie należy do platformowego executora po polityce repozytorium, ticketcie, ograniczeniu zakresu zapisu oraz lifecycle Git.
